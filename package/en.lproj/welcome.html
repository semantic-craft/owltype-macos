Famo (法墨) is an open-source modern Chinese input method that pairs a fast local engine with large-language-model and legal-writing features.

This installer places Famo in /Library/Input Methods. After the first install you will be asked to log out and back in once (later updates install automatically via Sparkle — no logout needed):

  1. If macOS asks whether to allow adding 法墨 Famo, click Allow.
  2. Then choose 法墨 Famo from the input menu, or press Control-Space to switch.

If Famo does not appear in the menu after a first install, or it appears but cannot type, open System Settings ▸ Keyboard ▸ Text Input ▸ Edit… and add 法墨 Famo once.

Famo does not modify your existing Squirrel/Rime setup, and it updates only from responsay.com — never from the upstream Squirrel feed.
