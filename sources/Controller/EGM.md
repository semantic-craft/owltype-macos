# Controller

## Overview

The macOS composition root and InputMethodKit controller connect the engine, host text fields, candidate presentation, settings, explicit AI actions, and installation recovery. `EngineRuntime` owns the process-wide engine and configuration lifecycle; individual `OwlInputController` instances own their sessions and host-bound transient work. [EngineRuntime.swift:EngineRuntime] [OwlInputController.swift:OwlInputController] [OwlApplicationDelegate.swift:OwlApplicationDelegate]

## Interface

- `EngineRuntime.start`, `redeploy`, `shutdown`, and `whileStopped` order engine lifecycle work; `applyKeyboardSettings` and `requestLiveSessionRefreshWhenIdle` activate configuration/resource changes. Controllers register weakly and share the same runtime instance. [EngineRuntime.swift:EngineRuntime]
- `OwlInputController.handle`, `activateServer`, `deactivateServer`, and `commitComposition` implement the IMK boundary. Candidate selection, removal, pinning, and paging feed back into the engine before `engineUpdate` redraws. [OwlInputController.swift:handle] [OwlInputController+Lifecycle.swift:activateServer] [OwlInputController+Lifecycle.swift:commitComposition]
- `engineUpdate` consumes commits, synchronizes schema/options, renders marked text, emits composition snapshots, and updates the sole SwiftUI candidate renderer. `apply` executes typed client writes; slash-command recovery also writes buffered literal text directly. [OwlInputController+EngineUpdate.swift:engineUpdate] [OwlInputController+ClientAction.swift:apply] [OwlInputController+Events.swift:handleAICommandDetector]
- `OwlAutomaticExpansionRuntime` publishes committed template indexes; the controller extension binds recognition and delivery to the originating host/session. `invokeTemplate` joins candidate, picker, and automatic-expansion routes. [OwlAutomaticExpansion.swift:OwlAutomaticExpansionRuntime] [OwlInputController+AutomaticExpansion.swift] [OwlInputController+EngineUpdate.swift:invokeTemplate]
- `OwlApplicationDelegate` wires injected snapshot/prompt/polish ports, global hotkeys, settings/onboarding windows, menu actions, distributed CLI notifications, and Sparkle. `OwlUpdateLogoutPrompt` records installation self-check verdicts; `OwlUpdateLogoutScheduler` schedules optional recovery. [OwlApplicationDelegate.swift:OwlApplicationDelegate] [OwlUpdateLogoutPrompt.swift:OwlUpdateLogoutPrompt]

## Invariants

- Configuration replacement validates the new configuration before discarding the last usable cache. Queued live resource refresh waits until every registered controller has no in-flight composition; background sessions are invalidated before the active session is refreshed. [EngineRuntime.swift:loadSettings] [EngineRuntime.swift:applyPendingLiveSessionRefreshIfIdle] [OwlInputController+Session.swift:hasInFlightComposition]
- Settings/onboarding schema changes use the idle queue. Requested schema failure is surfaced, and live schema state is updated only after successful selection; a preference alone is not proof the engine selected it. [OwlApplicationDelegate.swift:selectSettingsSchema] [OwlApplicationDelegate.swift:selectSchema] [OwlInputController+Session.swift:switchLiveSessionSchema]
- Delayed reranking and AI results carry session/generation/input/action identity. Obsolete work is cancelled or drained without applying; AI display changes additionally require the current first page and untouched highlight. Lane tasks cancel their predecessor. [OwlInputController+Session.swift] [OwlLaneTasks.swift:OwlLaneTasks]
- Nonempty marked text is resent even when unchanged; only empty-to-empty updates are suppressed. Candidate-free updates perform no caret query. Caret queries use character index zero, capability policy, validated screen geometry, and host-scoped remembered anchors. [OwlInputController+EngineUpdate.swift:show] [OwlInputController+EngineUpdate.swift:showPanel] [OwlApplicationDelegate.swift:lastCaretAnchor]
- Automatic expansion checks enabled template state, host scope, session/mode/revision, and marked-text ownership. An uncertain write is not replayed. The committed-text fallback waits outside the key handler and revalidates field, selection, original text, generation, and privacy. [OwlAutomaticExpansion.swift] [OwlInputController+AutomaticExpansion.swift]
- Template marker commits must resolve a current record; stale markers never become literal output. Focus-taking template delivery is deferred outside key handling and retains the captured target rather than borrowing a later active client. [OwlInputController+EngineUpdate.swift:consumeCommittedText] [OwlInputController+EngineUpdate.swift:invokeTemplate] [OwlInputController+Menu.swift:showOwltypePromptPicker]
- Native paired punctuation and smart punctuation retain host ownership and gate surrounding-text/replacement operations by capabilities. Legacy Wubi caret centering verifies the inserted pair before moving; untrusted replacement semantics degrade to ordinary insertion. [OwlInputController+NativePunctuation.swift] [OwlInputController+SmartPunctuation.swift] [OwlInputController+EngineUpdate.swift:commitApplyingAutoPair]
- Startup recovers template migration before seeding or managed patches, seeds only absent files in Owltype's own data directory, then binds the committed template index. [OwlApplicationDelegate.swift:setupEngine] [OwlApplicationDelegate.swift:seedUserDirIfNeeded]
- Version changes alone never arm logout guidance. A recorded self-check failure is rechecked before presentation; recovered sessions dismiss the request. User disposition is recorded before invoking logout, whose AppleScript runs off the IME main thread. [OwlUpdateLogoutPrompt.swift:runIfNeeded] [OwlUpdateLogoutPrompt.swift:OwlUpdateLogoutScheduler] [OwlUpdateLogoutPrompt.swift:OwlLogoutAction]

## Side Effects

- Writes host marked/committed text, may post guarded synthetic key events, opens panels/windows, and uses the clipboard for the emoji fallback when no client remains. [OwlInputController+ClientAction.swift:apply] [OwlInputController+SmartPunctuation.swift] [OwlInputController+EngineUpdate.swift:postLeftArrowKeyEvent] [OwlInputController+Menu.swift:showOwltypeEmojiPanel]
- Starts/stops engine sessions, invokes asynchronous provider/rerank work, reads/writes user configuration and migration state, persists preferences/diagnostics, posts notifications, manages event taps/timers, opens URLs/folders, and checks Sparkle updates. [EngineRuntime.swift] [OwlApplicationDelegate.swift] [OwlUpdateLogoutPrompt.swift]
- Self-check rechecks run process probes in a utility queue. Explicit logout can invoke macOS automation consent and system logout confirmation; an AppleScript delivery success is not evidence that the user completed logout. [OwlUpdateLogoutPrompt.swift:beginRecheck] [OwlUpdateLogoutPrompt.swift:OwlLogoutAction]
