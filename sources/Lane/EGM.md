# Lane

## Overview

Cloud AI features and their native adapters: conversation, selection polishing, structured drafting, source searches, optional composition candidates, provider configuration, streaming transport, and result writeback. Business rules and long-lived workflow state largely delegate to `OwlAIBusinessCore`, `OwlProviderCore`, and owned Rust sessions; Swift performs Keychain, network, preference, and host effects. [OwlAIContextAssembler.swift:OwlAIBusinessCore] [OwlLLMGateway.swift:OwlProviderCore]

## Interface

- `OwlLLMGateway.complete` and `stream` choose Chat Completions or Responses through `OwlProviderCapabilities`; `OwlLLMTransport` is the injectable byte transport. `OwlResponsesWire` builds the four dialects and parses responses. [OwlLLMGateway.swift:OwlLLMGateway] [OwlResponsesWire.swift:OwlResponsesWire]
- `OwlProviderAuthGate.resolve` returns ready routing/key, unconfigured, or missing-key. `OwlProviderProfileStore` exposes profile CRUD; `OwlProviderRegistry` coordinates profiles, secrets, workspace configuration, and verification markers. [OwlProviderAuthGate.swift:OwlProviderAuthGate] [OwlProviderProfile.swift:OwlProviderProfileStore] [OwlProviderRegistry.swift:OwlProviderRegistry]
- `OwlAskAnythingOpening` exposes readiness and an attributed stream. `OwlAIConversationModel` submits, regenerates, stops, resets, and tears down a conversation; `OwlAIContextAssembler` accepts explicit selection, question, and history. [OwlAskAnythingModule.swift:OwlAskAnythingOpening] [OwlAIConversationModel.swift:OwlAIConversationModel] [OwlAIContextAssembler.swift:OwlAIContextAssembler]
- `OwlSelectionPolishService`, `OwlAIPolishService`, `OwlPromptOptimizeService`, and `OwlGoalBriefService` expose rewriting/replies and structured drafts. `OwlStructuredDrafting` returns a nonempty ready document or bounded clarification questions. [OwlSelectionPolish.swift:OwlSelectionPolishService] [OwlAIPolishService.swift:OwlAIPolishService] [OwlStructuredDrafting.swift:OwlStructuredDrafting]
- `OwlSourceVerificationService.verifyStructured` combines configured search services and judgment; local anchor extraction, case-number checking, source menus, CNKI expressions, and safe-link routing are separate value interfaces. [OwlSelectionPolish.swift:OwlSourceVerificationService] [OwlVerificationAnchors.swift] [OwlVerificationRouting.swift] [OwlCNKIExpertQueryBuilder.swift]
- `OwlAICandidateService` generates up to three cleaned associations and optionally selects one of at most 32 local candidates. `OwlAIWritebackCoordinator` dispatches by captured typing/selection/standalone context; `OwlTextInserter` exposes the AX/paste/copy ladder. [OwlAICandidateService.swift:OwlAICandidateService] [OwlAIWritebackCoordinator.swift:OwlAIWritebackCoordinator] [OwlTextInserter.swift:OwlTextInserter]

## Invariants

- Cloud, writing-panel, web-search, AI association, English-candidate, and Jev-rerank preferences default off. Feature services/controllers own admission; transport-only APIs do not independently enforce every cloud/privacy gate. Enabled candidate features can send composition input and optional context asynchronously. [OwlCloudFoundation.swift:OwlCloudPreferences] [OwlAIWritingSettings.swift:OwlAIWritingSettings] [OwlAskSearchResolver.swift:OwlAskWebSearchSettings] [OwlAICandidatePreferences.swift] [OwlStreamingChatClient.swift:OwlStreamingChatService] [OwlAICandidateService.swift:generateCandidates]
- Profile JSON stores secret account names rather than API keys. Registry changes stage replacement secrets before committing profiles, retain old keys while referenced, and require replacement credentials across origins. Probe verification records past successful calls; it does not promise current model availability. [OwlProviderProfile.swift:OwlProviderProfile] [OwlProviderRegistry.swift:OwlProviderRegistry] [OwlProviderRegistry.swift:OwlProviderKeyVerification]
- Keychain access is disabled by `OwlTestStorage`. Legacy migration preserves the old DeepSeek key as fallback. Invalid workspace input does not overwrite usable configuration. [OwlProviderProfile.swift:OwlProviderKeychain] [OwlProviderProfile.swift:OwlProviderMigration] [OwlProviderProfile.swift:OwlQwenWorkspaceSettings]
- Provider rules own dialect, low-latency thinking, sampling, error classification, and bounded retry policy. Interactive, drafting, and connectivity purposes have distinct policies; connectivity probes make one real request. Usage telemetry stores model/token counts, not content. [OwlLLMGateway.swift:OwlLLMCallPurpose] [OwlLLMGateway.swift:complete] [OwlProviderProfile.swift:OwlProviderConnectivityCheck] [OwlCloudFoundation.swift:OwlCloudUsageTelemetry]
- Native transport preserves raw bytes; Rust stream sessions own UTF-8/SSE framing. ABI chunks are capped at 65,536 bytes without imposing that cap on protocol lines. Stream termination cancels upstream work; Responses failure frames become errors. [OwlLLMGateway.swift:OwlURLSessionTransport] [OwlLLMGateway.swift:OwlProviderStream] [OwlResponsesStreamingClient.swift:OwlResponsesStreamingClient]
- Conversation callbacks are admitted by Rust generation, including provider changes. Ask search may fail over only before output and only for admitted configuration refusals; attribution follows the actual route. Unknown failures do not automatically send the question to every configured provider. [OwlAIConversationModel.swift:receive] [OwlAskAnythingModule.swift:pump] [OwlAskSearchResolver.swift:OwlAskSearchFailover]
- Ask search performs a distinct DeepSeek Search request before generation. Source verification may search DeepSeek and Doubao concurrently; sources derive from returned search records, not model-invented URLs. Local anchors start pending; absence of results is not proof a claim is false. [OwlAskAnythingModule.swift:streamWebSearch] [OwlSelectionPolish.swift:verifyStructured] [OwlDeepSeekSearch.swift:OwlWebSearchGrounding] [OwlVerificationAnchors.swift:OwlFactCoordinateExtractor]
- Structured drafting validates input before authorization, protects sentinel tags without rewriting ordinary code brackets, and degrades malformed/empty results to clarification. Dual-polish parsing guarantees two outputs and reply parsing three, but fallback outputs can duplicate the original or use fixed reply text; distinctness and semantic fidelity are not guaranteed by parsing. [OwlStructuredDrafting.swift:draft] [OwlStructuredDrafting.swift:protectedDraft] [OwlDualPolishParser.swift:OwlDualPolishParser]
- Typing writeback reports direct IMK insertion after issuing the call; paste success reports event posting, not host readback. Standalone writeback copies. Paste restoration saves only the prior string and restores it after 0.5 seconds when present. [OwlAIWritebackCoordinator.swift:writeback] [OwlTextInserter.swift:OwlPasteInserter]

## Side Effects

Reads/writes private provider JSON, Keychain entries and preferences; posts configuration notifications; sends authenticated provider/search/model-list/probe requests; streams content; updates token telemetry; writes host text and the clipboard; posts Command-V events. Local query/anchor/routing builders only return values, with URL opening owned by UI callers.
