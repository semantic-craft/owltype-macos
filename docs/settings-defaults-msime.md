# 键盘与快捷键设置：默认值对照水杉 macos-v0.55.0

核对日期 2026-10-29，#315。上游为 [metasequoiaime/msime](https://github.com/metasequoiaime/msime)
`macos-v0.55.0`（`208c10e`，与 [msime-source.json](../rust/msime-source.json) 一致）。macOS 发行版是
full edition，`Preferences::for_edition` 对 full 返回 `Default`。

Owltype 默认值以 [开关目录](../sources/Settings/OwlKeyboardSettingsCatalog.swift) 和
[键盘偏好](../sources/Settings/OwlKeyboardPreferences.swift) 为准；只在键从未写入时生效，已存的值不受影响。

上游路径简写：`P` = `crates/client-core/src/preferences.rs`，
`M` = `platforms/macos/src/settings/AppearancePreferences.mm`。

## 有意差异（#315 列出的三项）

1. 中文模式下单按 `/`（未开 “/” 选单）：Owltype 先上屏高亮候选，再切到英文并输入 `/`。上游只上屏候选再接 `/`，不切英文（`crates/input-runtime/src/runtime.rs`:2830-2889）。
2. 模板、片段与提示词只在 K 加触发词后出现。上游新装默认同样不把快捷短语混入普通候选；#315 正文所说“上游默认 true”指的是缺键旧文档的读法。
3. 用户置顶排在引擎顺序之前，规则见 [input-habits-design.md](input-habits-design.md)。

## 未解决

翻页两项与上游相反，不在三项有意差异内。改默认值只影响从未改过这两项的用户，已存的值不变；
是否改由用户决定，见 #315。
