# Sentence lattice

## Overview

Chinese sentence graph construction, beam decoding, typo alternatives, candidate merging, static/personal n-gram scoring, optional octagram collocations, and local neural reranking. Lookup and typo-edge sources are injected closures, so decoding does not depend directly on SQLite. Files used only by `cfg(test)` modules are excluded from the production contract. [mod.rs:LatticeLookup] [mod.rs:TypoEdgeSource]

## Interface

- `LatticeOptions`, `SentencePath`, `TypoEdge`, `TypoSentence`, and `PinnedSpan` define decode inputs/results. `decode_sentences`, `decode_constrained_sentences`, and `decode_pinned` expose ordinary and constrained search; `SentenceNgramTables` retains loaded static tables for the active dictionary. [decode.rs:LatticeOptions] [decode.rs:decode_sentences] [decode.rs:decode_constrained_sentences] [decode.rs:decode_pinned]
- `merge_lattice_candidates` and the internal decode/merge split place sentence rows into caller candidates. Owned and borrowed variants share semantics while preserving cached path ownership. `whole_sentence_insert_position` identifies the protected leading dictionary block. [merge.rs:merge_lattice_candidates] [merge.rs:DecodedSentences] [merge.rs:merge_decoded_borrowed] [merge.rs:whole_sentence_insert_position]
- `NgramTable::load`/`shared`, `bigram`, `trigram`, and `score` query MSNG models. `BigramMemo` caches transition scores; `PersonalNgram` adds/removes counts and supplies context probabilities without persistence. [ngram.rs:NgramTable] [decode.rs:BigramMemo] [personal.rs:PersonalNgram]
- `GramDb::load`/`shared`/`evict_shared` and `query` expose read-only octagram collocations under `GramConfig`. `NeuralReranker` scores/reorders existing paths using `shared_sentence_model`; it does not generate sentences. [octagram.rs:GramDb] [octagram.rs:GramConfig] [neural.rs:NeuralReranker]

## Invariants

- Graph edges own their text and advance between syllable columns. Repeated spans reuse lookup results; empty values are excluded. Constrained search filters before the requested per-span cap so qualifying low-ranked words survive. Pinned spans are caller-supplied, nonoverlapping, in-range, one-character-per-syllable constraints; missing pinned words receive a minimum-weight edge. [decode.rs:build_graph] [decode.rs:build_graph_borrowed] [decode.rs:decode_constrained_sentences] [decode.rs:decode_pinned]
- Beam tie movement intentionally reproduces libc++ partial-sort/full-sort behavior; replacing it with Rust unstable or stable sorting changes candidate outcomes. Streamed selection preserves the same arrival order and finishes the heap before consuming a column. Traceback borrows graph edges and materializes only retained sentence values. [cxx_sort.rs:partial_sort] [cxx_sort.rs:push_partial] [cxx_sort.rs:finish_partial] [cxx_sort.rs:sort] [decode.rs:decode_graph_with_terminal]
- Bigram search bonuses clamp negative static scores to zero; trigram scores rescore surviving paths afterward. Personal transitions use separate count spaces, saturating count additions, floored removals, context confidence, and bounded positive lift. Personal model access requires the owning store's lock; this module owns no persistence or decay loop. [decode.rs:decode_graph_with_terminal] [decode.rs:rescore_with_trigram] [decode.rs:personal_transition] [personal.rs:CountTable] [personal.rs:PersonalNgram]
- Default beams are 32, typo beams eight, and phrase spans seven syllables. Product static-table options request six paths; neural scoring covers at most 12 with the last 64 context characters. Neural/static interpolation uses coefficient 0.5 and preserves ties and the unscored tail. Missing or malformed neural models leave lattice output usable. [decode.rs:LatticeOptions] [decode.rs:SentenceNgramTables] [neural.rs:score_order_into] [neural.rs:rerank_order_into]
- Ordinary merge requires at least two complete Pinyin syllables; typo planning requires at least three. Typo results must use a correction and differ from the literal path. The ordinary policy requires improvement; the explicit nonleading policy may retain a lower-scoring alternative. Infinite default lead margin keeps corrections behind sentence rows. [merge.rs:decode_lattice_with_typo_policy] [merge.rs:decode_graph_sentences_with_policy] [decode.rs:decode_typo_on_graph_with_policy] [decode.rs:TypoSentence]
- Leading exact dictionary rows remain ahead of sentence rows. Merge deduplicates by sentence text and uses explicit source/order rules; numeric row weights are not an instruction to resort the list. Collocation ownership and neural duplicate fallback depend on the supplied options. [merge.rs:whole_sentence_insert_position] [merge.rs:merge_decoded_paths] [merge.rs:reranked_block]
- Static MSNG/octagram mappings require immutable files installed by rename and no-follow regular-file opens. MSNG bounds/count/order validation precedes lookup, with duplicate keys resolving to the first entry. Shared caches remember failures by path (MSNG/neural capacity eight, octagram four); callers must respect resource-path identity. Neural reads are capped at 64 MiB. [ngram.rs:load] [ngram.rs:shared] [octagram.rs:load] [octagram.rs:shared] [neural.rs:load_model]
- Octagram scores are collocation strength, not probabilities; absent matches return the configured penalty. The injected scorer must use the decode score domain consistently. Context tails retain eight code points and scoring activates only with a scorer and positive weight. [octagram.rs:query] [decode.rs:CollocationScorer] [decode.rs:CollocationTail] [decode.rs:decode_graph_with_terminal]

## Side Effects

Mutates caller candidate/path buffers, in-memory personal counts and memo tables; invokes caller-provided lookup/typo/scoring closures. Model access reads/maps local files, takes cache mutexes, and retains Arc-backed models. Neural rerankers mutate their session-owned inference caches. No network requests or direct learning-file writes occur here. [merge.rs:merge_decoded_paths] [personal.rs:PersonalNgram] [ngram.rs:shared] [octagram.rs:shared] [neural.rs:NeuralReranker]
